# SkorText TV

Live-Ergebnisse, Tabellen und türkische Nachrichten im Videotext-Stil – als App für Android TV / NVIDIA Shield.

**Installation auf der Shield:** App „Downloader“ öffnen und diese Adresse eingeben:

https://github.com/Postmen1971/SkorText/releases/latest/download/skortext.apk

Die APK wird bei jeder Änderung automatisch von GitHub gebaut (Reiter „Actions“).
